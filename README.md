Entry for the [make.fun](https://make.fun/c/u-eager-stork-81-9647-the-moon-gets-one-star-768236e5) competition **"The Moon Gets One Star"**.

## What it does

`main.py` (pure Python standard library, no dependencies) writes one
one-star review of the Moon — 1 to 120 characters — to `/output/entry.txt`:

> 1 star. Ghosted me for two weeks, came back thinner, then blamed the tides. Zero accountability, all glow.

106 characters, one line, UTF-8, no trailing newline. Deterministic (every
run writes the exact same bytes).

## Run it

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py out.txt    # write to a custom path (local testing)
```
